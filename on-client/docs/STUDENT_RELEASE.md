버전은 **검증 중인 버전**입니다. 패키지 버전은 `on-client/package.json`의 `0.2.14`입니다. v1.0이 아닙니다. 19단계 실제 조치 집행, 같은 커밋에 이 기록이 포함된 누적 재현, 공식 접수 수용은 끝나지 않았습니다.

## 이동 절차

1. Node.js `24.19.0`을 설치하고 `node -v`, `npm -v`로 버전을 확인합니다.
2. 빈 폴더의 상위에서 `git clone https://github.com/nabell0/choi-bujang-secret-vault.git`을 실행합니다.
3. 복제된 저장소에서 `git checkout dc1af82bd6063a660f70cbf37c80411d80e1f90b`를 실행합니다.
4. `on-client`로 이동해 `npm run demo`를 실행합니다. `package.json`에 `dependencies`가 없으므로 `npm install`은 이 커밋의 실행 조건이 아닙니다.
5. 콘솔의 `케셰브 예제:` 뒤에 나온 주소만 브라우저에서 엽니다. 기본 포트는 5189입니다. 그 포트가 이미 사용 중이면 그 셸에서만 `ON_PORT`를 다른 번호로 지정합니다.
6. 기존 폴더의 `.env`, 인증 파일, 기기 개인키, 토큰은 복사하지 않습니다.
7. 서버 프로세스를 종료한 뒤 같은 명령으로 다시 실행하고, 콘솔 문구와 첫 화면이 같은지 확인합니다.

`tools/start-alekov.ps1`은 저장소 밖에 네이티브 호스트 설정을 만들 수 있어 이번 재현에서는 실행하지 않았습니다. `npm start`도 실행하지 않았습니다.

## 데이터 보존·백업·복원

- 커밋된 원문의 백업은 위 저장소의 Git 이력입니다. 복원 단위는 `dc1af82bd6063a660f70cbf37c80411d80e1f90b`입니다.
- 복제에는 커밋된 파일만 들어갔습니다. 커밋하지 않은 파일, `.env`, 인증 파일, 토큰은 복제본에 없습니다.
- 원래 폴더는 삭제하거나 초기화하지 않았습니다. 재현 뒤 `git status`는 `main...origin/main`이고 HEAD는 같은 커밋이었습니다. 이 문서를 추가하기 전에는 변경 파일이 없었습니다.
- 복원하는 사람은 저장소 URL을 복제한 뒤 위 커밋을 체크아웃합니다. 비밀값은 공식 비밀 입력란에 다시 입력합니다. 이 문서나 Git에 비밀값을 넣지 않습니다.
- 제한: 이 커밋만 복제하면 이 릴리스 기록, 커밋되지 않은 작업, 로컬 인증 상태는 복원되지 않습니다. 포트 5189를 이미 쓰는 프로세스가 있으면 복제본은 다른 포트를 지정해야 합니다.
