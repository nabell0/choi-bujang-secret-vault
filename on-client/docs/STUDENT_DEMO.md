# 케셰브 시연 순서

이 문서는 학생 시연 정리입니다. 제공 문서, `STUDENT_RELEASE.md`, `STUDENT_RUNBOOK.md`, 학생 화면 코드는 수정하지 않았습니다. 예제 서버를 이 문서를 쓰면서 다시 켜지 않았습니다. 아래에 적은 화면은 2026-11-06에 원래 폴더의 `http://127.0.0.1:5189/`에서 본 기록입니다.

버전은 검증 중인 버전입니다. 패키지 버전은 `on-client/package.json`의 `0.2.14`입니다. v1.0이 아닙니다. 22단계 복제 기록의 커밋 `dc1af82bd6063a660f70cbf37c80411d80e1f90b`와 이 문서의 화면 확인은 서로 다른 커밋입니다. 둘을 합쳐 최종 성공으로 적지 않습니다.

## 1. 제공 기능과 학생 기능

제공 기능은 `on-client/public/app.js`와 `on-client/src/server.mjs`가 처리합니다. 학생 기능은 `on-client/student/extension.mjs`가 받은 값을 표시합니다.

| 구분 | 화면에서 보는 것 |
|---|---|
| 제공 | 탭 `보호 현황`, `업무 앱`, `보안 기록`. 버튼 `다시 불러오기`, `설치 패키지 조회`, `패키지 조회 취소`, `도움정보 불러오기`, `AI 설명 요청`, `대상과 조치를 확인했으며 집행합니다`, `원천 결과만 재조회`, `조치 화면 취소` |
| 제공 | `내 기기`, `내 세션`, 업무 앱 접속 요청, 예제 서버 `npm run demo` |
| 학생 | 계정·기기·세션·판정·보안 기록에 예시 값이라는 문장을 붙임 |
| 학생 | 상태 칸 순서: 기기, 세션, 알림, 도움정보, 추가 조회. 버튼 `다시 조회` |
| 학생 | 추가 조회에 필드가 없으면 `확인 불가`. `demo`이면 `SDP 미연결`을 따로 표시 |

## 2. 시연 순서

앱 폴더는 `package.json`이 있는 `on-client`입니다. 이 PC에서 잰 경로는 `C:\Users\user\Desktop\choi_bujang-secret-vault\on-client`이며, 다른 PC의 실행 경로가 아닙니다. 이미 `http://127.0.0.1:5189/`가 응답하면 서버를 다시 켜지 않습니다.

1. `on-client`에서 PowerShell을 열고 `npm run demo`를 실행합니다. 콘솔 문구 `케셰브 예제: http://127.0.0.1:5189`를 이 PC에서 확인했습니다.
2. 브라우저에서 `http://127.0.0.1:5189/`를 엽니다. 제목 `케셰브 · ZTNA & XDR`을 확인했습니다.
3. `보호 현황`을 엽니다.

핵심 기능은 다음 세 가지입니다.

1. 학생 상태 칸의 기기와 세션. `연습 PC · 확인 불가(unknown)`, `practice-session · 활성(active)`가 보이고, 각각 예시 값이며 이 PC에서 측정한 값이 아니라는 문장이 있습니다.
2. 추가 조회의 `다시 조회`. Tab으로 이동한 뒤 Enter를 누릅니다. `조회 중` 동안 버튼이 비활성화되고, 이어서 `조회 완료`가 됩니다. CPU, 메모리, 디스크, 네트워크, 방화벽, System, Application은 `확인 불가`입니다. `SDP 미연결`이 따로 보입니다.
3. 알림과 도움정보. 알림에는 예제 기기 상태와 `event-01` 안내가 있습니다. 도움정보는 `도움정보를 아직 불러오지 않았습니다.`입니다. `도움정보 불러오기`는 이 확인에서 누르지 않았습니다.

`practice-user`, `practice-pc`, `practice-session`, `event-01`, `2026-10-12T03:00:00.000Z`는 예시 값입니다. 조회 시각 `2026-11-06T06:31:13.381Z`는 이번 `/api/devices` 응답에서 받은 값입니다. 건수 4, 23, 10은 이 화면에 없습니다.
